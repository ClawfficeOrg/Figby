# E2E Tests — Figby TUI Image Editor, Layers & Banner Finale

Two suites, split on purpose:
- **Headless structural** (`figby-rs/tests/e2e_art.rs`, 4 tests): figmap
  loads, dims, layer names/counts, frame counts, gold-cell content, light
  rig shape, `into_runtime` + `composite()`. Fast, runs in CI.
- **Non-headless PTY** (`scripts/e2e-art-tmux.sh`, 15 checks, ~1 min):
  real TUI in tmux — Open-dialog typing + Enter, canvas content, tool keys
  via status bar, timeline/export dialogs, `--play --loop` progress.
  Run: `./scripts/e2e-art-tmux.sh` (exit 0 = all pass). The PTY suite is
  the real e2e; the headless tests only pin the scene contract.

Art scenes live in `assets/e2e-art/*.figmap`, generated by
`scripts/gen-e2e-art.py` (all original tribute work — 8-bit *style*,
never ROM copies). Regenerate: `python3 scripts/gen-e2e-art.py`.
`--play` checks need a PTY (plain pipes fail with `Device not configured`).

## 1. Image editor tools (first priority) — tribute sprites

Setup per sprite: open `assets/e2e-art/sprite-<name>-tribute.figmap`
(`Ctrl+O` → Open mode lists `.figmap`; ImageEditor `Ctrl+O` opens the
*image* dialog instead — use `Alt+F` File menu or FontEditor-mode `Ctrl+O`).
Reference scenes: plumber (night), quest (day), invader (night).

Tool keys (verified live 2026-09-23, AsciiPreview/ImageEditor modes):
`b` Brush, `u` Move, `r` Rotate, `v` Select, `l` Lasso, `c` Circle,
`p` Polygon, `g` Fill, `i` Line, `e` Eraser, `d` Eyedropper, `a` Spray,
`t` Text (see §1.8), `m` Emitter (mouse-only), `n` Lighting (see §4),
`k` Braille. `Space`/`Enter` paints at cursor for
Brush/Eraser/Line/Fill/Spray; Braille uses `Space`/`Enter` to toggle the
dot under its 2×4 sub-cursor (arrows move the dot, not the cell).
